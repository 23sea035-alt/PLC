# PLC PROGRAMME DEVELOPMENT

Fatek PLC ladder programs created with **WinProladder** software.

## About

This repository contains PLC program files (`.pdw`) for **Fatek** programmable logic controllers (FBs series: FBs-20MC and FBs-14MA). The programs are developed and edited using the Fatek WinProladder IDE.

## How to Open

1. Download and install **Fatek WinProladder** (available from the [Fatek](https://www.fatek.com/) official website).
2. Open the application and select **File → Open**.
3. Choose the desired `.pdw` file from this repository.

## Requirements

- Fatek FBs series PLC (FBs-20MC / FBs-14MA) or WinProladder simulation mode
- Windows OS
- WinProladder software (v5 or later recommended)
